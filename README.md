An end-to-end empirical cognitive science and data analysis project investigating whether objective daily smartphone screen time is associated with sustained attention slips and cognitive interference control in college students.

## Overview
* **Domain:** Cognitive Science, Empirical Psychology, Data Science
* **Sample:** Community college students ($N = 30$, campus computer lab setting)
* **Independent Variable (IV):** 7-day daily average social media screen time (filtered to phone-only via iOS Screen Time / Android Digital Wellbeing)
* **Secondary Measure:** 9-item Social Media Disorder Scale (SMDS; van den Eijnden et al., 2016)
* **Dependent Variables (DVs):** 
  * Sustained Attention to Response Task (SART) commission errors & reaction time
  * Computerized Stroop color-word task match vs. mismatch reaction time & accuracy

## Live Web Experiment
Built as a zero-dependency single-page web application deployed via **GitHub Pages**:
* Informed consent with neutral framing to prevent demand characteristics and explicit minimal-risk disclosure.
* Built-in visual guides instructing iOS users to deselect shared Mac/iPad devices.
* Millisecond-accurate keyboard event timing (`performance.now()`) and automatic `.csv` row export.
